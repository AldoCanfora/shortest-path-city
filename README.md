# Shortest Path City

Find the Shortest Path Through Your City!

## How to Play ShortestPathCityGoal: 
Navigate from one neighbourhood to another by naming adjacent zones — in as few hops as possible.
Each round you get two neighbourhoods: a Start (green) and a Destination (red). Your job is to trace a path between them, one adjacent hood at a time. The map stays hidden until the game ends.
Type the name of a neighbourhood that shares a border with your current position and press Guess.


Try it here: [shortest-path-city](https://aldocanfora.github.io/shortest-path-city/)
